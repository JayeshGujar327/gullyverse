# GULLYVERSE

## The Indian Hip-Hop Culture Universe

GULLYVERSE is an interactive web platform for exploring Indian hip-hop through artists, songs, regional scenes, history, cyphers, battles, producers, education and culture.

## Features

- Artist discovery and profiles
- Songs and music discovery
- Regional hip-hop map
- Indian hip-hop history
- Cyphers and battles
- Producer discovery
- Rap learning section
- Artist comparison
- Hip-hop journey
- Quizzes and playlists
- Artist submission and awards
- Interactive music player
- Search, queue and lyrics
- Creator and Admin Dashboard
- About GULLYVERSE
- Responsive navigation

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- HTML
- CSS
- JavaScript / TypeScript

## Run Locally

``bash
npm install
npm run dev
``

## Production Build

``bash
npm run build
``
